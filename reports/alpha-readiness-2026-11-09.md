# Проверка подготовки alpha — 2026-11-09

Реализация M0–M13, текущая версия `0.2.0-SNAPSHOT`. M14 остаётся в работе: внешняя площадка,
итоговая версия и координаты публикации (O8) ещё не утверждены.

## Проверенные изменения

- `GpuAssert` выбирает допуск builtin по фактическому f32/f64, учитывает достижимые вызовы и выбранный вариант ядра.
  Неиспользуемые варианты больше не увеличивают допуск. Регрессия на фейковом устройстве отклоняет ошибку в 1 ULP
  у выбранного double-sqrt, даже если основное ядро использует sin с допуском 4 ULP.
- Контрпример с вычитанием близких чисел закрепляет ограничение автодопуска: максимум допусков операций
  не является доказанной границей ошибки составного выражения. Числа в `builtins.def` не расширялись.
- `publishLocal` создаёт Maven-репозиторий `build/local-maven` с девятью модулями, sources JAR и plugin marker.
  Самостоятельный проект подключается через Gradle metadata и отдельно только POM, без project-зависимостей,
  composite build, flatDir и TestKit plugin-classpath.
- Проверены processor и weaving для main/test, опубликованный `test-support`, повторная сборка,
  принудительный JVM-fallback, обязательный OpenCL и скрипт установленного дистрибутива.
- Исправлена потеря `Fallback.NEVER` при неудачном создании default-контекста: отсутствие устройства теперь
  отклоняет запуск без исполнения JVM-тела. Регрессии проверяют повторные вызовы, scoped-контекст и reset.
- В `app` исправлены устаревшие ожидания тестов для существующей экспериментальной формулы vectorAdd
  и восстановлена фактическая проверка результата в Main. Формула ядра сохранена.

## Среда и результат

Windows, NVIDIA GeForce RTX 5070, драйвер 595.97. Корневая сборка — Gradle 9.8.1 на JDK 21 с toolchain 25;
ручная проверка независимого потребителя и его скрипта — JDK 25. JVM Gradle потребителя должна быть 25+.

```powershell
.\gradlew.bat build :test-support:deviceTest :runtime:deviceTest :codegen-opencl:deviceTest :app:deviceTest
```

Результат: `BUILD SUCCESSFUL`, `verifyModuleBoundaries` — 11 модулей без нарушений.
Gradle переиспользовал актуальные результаты неизменённых задач; изменённые тесты выполнялись заново.

| Задача | Тестов | Ошибок | Пропусков |
|---|---:|---:|---:|
| `:runtime:test` | 171 | 0 | 0 |
| `:runtime:deviceTest` | 46 | 0 | 0 |
| `:test-support:test` | 85 | 0 | 0 |
| `:test-support:deviceTest` | 44 | 0 | 0 |
| `:gradle-plugin:test` | 9 | 0 | 0 |
| `:app:test` | 17 | 0 | 0 |
| `:app:deviceTest` | 4 | 0 | 0 |

Прямая проверка sin/cos/sqrt/fma: 2048 входов для каждой функции и каждого типа (f32/f64),
включая окрестность π, нули, отрицательные значения, NaN и бесконечности. Все проверки укладываются
в табличные допуски. Историческое наблюдение 16 ULP для double-sin не воспроизведено на этой скалярной выборке;
оно не считается опровергнутым для всех аргументов и векторных перегрузок. AMD и Intel не проверены.

Дополнительно успешно выполнены:

```powershell
.\gradlew.bat -p examples/standalone test runFallback runDevice installDist
& .\examples\standalone\build\install\gpu-standalone\bin\gpu-standalone.bat device
.\gradlew.bat :app:run --args=1
```

Standalone вывел `[3.0, 5.0, 7.0, 9.0]` с `BACKEND JVM` и с `BACKEND OPENCL` в соответствующих режимах.
Установленный скрипт подтвердил `BACKEND OPENCL`. Пример app подтвердил `vectorAdd: OK (1 elements)`.
